# Boltha App - Designer Brief

## Project Overview
**Boltha** is a step-tracking rewards app that gamifies fitness by rewarding users with "Bolts" (digital currency) for walking and achieving daily step goals.

## Brand Identity
- **Name**: Boltha
- **Concept**: Steps + Rewards = Motivation
- **Target Audience**: Health-conscious individuals, fitness enthusiasts, gamification lovers
- **Platform**: iOS/Android mobile app

## Design Requirements

### 🎯 **Priority 1: App Icon (1024x1024 PNG)**
**Concept**: Footprint + Coin/Reward symbol
- **Style**: Minimalist, modern, iOS-compliant
- **Colors**: Primary Blue `#007AFF` + Gold `#FFD700`
- **Must work at**: 16px to 1024px (highly scalable)
- **Reference**: See `assets/source/icon-concept.svg` for basic concept

### 🎯 **Priority 2: Splash Screen (1284x2778 PNG)**
**Concept**: Clean loading screen with centered app icon
- **Background**: Solid `#007AFF` (Primary Blue)
- **Icon**: Centered, ~200px size, white/gold version for contrast
- **Style**: Professional, minimal

### 🎯 **Priority 3: App Store Mockup**
**Concept**: Realistic iPhone home screen showing Boltha among popular apps
- **Device**: iPhone 15 Pro or similar
- **Context**: Home screen with Instagram, WhatsApp, etc.
- **Purpose**: Marketing/presentation visual

## Color Palette
```
Primary Blue:    #007AFF
Gold (Bolts):    #FFD700

Background:      #F2F2F7
White:           #FFFFFF
Text Dark:       #000000
```

## Design Elements
- **Footprint/Step**: Main symbol representing activity tracking
- **Coin/Bolt**: Secondary element representing rewards
- **Lightning Bolt**: Symbol for "Bolts" currency (⚡)
- **Clean Lines**: Modern, professional aesthetic
- **Rounded Corners**: iOS-style friendly design

## Technical Specs
- **App Icon**: 1024x1024 PNG, transparent background
- **Splash**: 1284x2778 PNG, `#007AFF` background
- **Mockup**: High-res PNG/JPG, realistic lighting
- **Source Files**: AI/Sketch/Figma preferred

## Inspiration Keywords
- Fitness tracking apps (Strava, Nike Run)
- Reward/gamification apps (Sweatcoin, Achievement)
- Clean iOS design (Apple's own apps)
- Step/footprint iconography
- Cryptocurrency/reward symbols

## Success Criteria
✅ **Recognizable** at small sizes (16px)  
✅ **Professional** enough for App Store  
✅ **Unique** stands out among other apps  
✅ **Relevant** clearly represents step-tracking + rewards  
✅ **Scalable** works across all device sizes
